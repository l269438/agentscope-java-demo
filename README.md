按文章篇次整理的Java电商选购示例。每篇使用“编号 + 中文名称”的独立Maven目录，包含源码、测试、README和运行入口；公共配置与日志单独维护。

JDK17+、Maven3.8+、AgentScope Java2.0.3。GitHub仓库为`l269438/agentscope-java-demo`，当前私有。

## 运行某一篇

在仓库根目录执行：

```sh
sh '01-ReAct与工具调用/run.sh'
sh '02-工具权限与人工确认/run.sh'
```

也可进入对应目录运行`sh run.sh`。默认执行本篇离线检查，不请求外部模型；脚本先构建并安装该模块及其依赖，再运行检查类。Maven未加入PATH时，通过`MAVEN_CMD`指定mvn完整路径。

IDE打开根目录`pom.xml`导入全部模块。原Java包名与类名保持不变，运行时工作目录设为仓库根目录；`.env`、`runs/`和持久状态仍集中在根目录。各篇数据文件位于自己的`fixtures/`中。

## 全量与单篇测试

```sh
mvn -B -ntp test
node --test tests/*.test.mjs

# 只检查02及其依赖
mvn -B -ntp -pl '02-工具权限与人工确认' -am test
```

需要从IDE运行跨模块入口时，可先执行`mvn -B -ntp install`。以上默认检查使用固定响应或只读工具，不调用云模型、不启动子Agent或Docker容器。

## 模型配置

复制`.env.example`为根目录的`.env`并填入本机配置，也可使用环境变量；环境变量优先。不要提交密钥。

本机已有Ollama与支持工具调用的模型时，启动01选购网页：

```sh
DEMO_PROVIDER=ollama DEMO_MODEL=qwen3:4b-instruct sh '01-ReAct与工具调用/run.sh' --web
```

打开`http://127.0.0.1:18181/`，输入预算与要求。点击发送后，模型调用商品与库存工具，右侧展示同次执行的工具链和事件；展开步骤查看参数与结果。

DashScope默认使用`qwen-plus`，需要`DASHSCOPE_API_KEY`。云模型请求可能计费；服务只监听本机，没有公网身份认证。02—10的模型入口、参数与操作条件见各篇README，默认脚本只做离线检查。

## 数据与运行记录

商品、价格与库存均为模拟数据。查询不锁库、不下单、不支付；02仅在批准后保存进程内模拟选购清单。运行结束状态和业务核对分开记录，既有偏差与待完成项保留在案例清单中。

`runs/`保存新执行的输入、上下文、事件、日志和结果；历史运行原件保留在原机器，未随仓库上传。`.env`、`runs/`、所有模块的`target/`、IDE本机配置和私钥文件均由Git忽略。

旧布局记录保留在[历史说明](docs/历史使用说明-单工程.md)，其中路径与命令用于回查。当前运行以本README和编号章节为准。
